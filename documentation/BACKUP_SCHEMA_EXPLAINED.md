# Smart-AutoClicker-II Backup Schema (Exhaustive)

This document provides a comprehensive reference for the backup files (`.zip`) generated by Smart-AutoClicker-II. It details every field available in the JSON configurations for both Smart and Dumb scenarios.

---

## 1. Archive Structure

The backup is a standard ZIP archive.

```text
Backup.zip
├── <Smart_ID>/              # Folder for a Smart Scenario
│   ├── <Smart_ID>.json      # The configuration file
│   ├── condition_1.png      # Image asset referenced by a condition
│   └── ...
├── dumb-<Dumb_ID>/          # Folder for a Dumb Scenario
│   └── <Dumb_ID>.json       # The configuration file
```

---

## 2. Shared Root Metadata

Every scenario JSON starts with these top-level fields:

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | Int | Database schema version (e.g., 20). |
| `screenWidth` | Int | Device screen width in pixels at export time. |
| `screenHeight` | Int | Device screen height in pixels at export time. |
| `scenario` | Object | **[Smart Only]** Full hierarchy of the Smart Scenario. |
| `dumbScenario` | Object | **[Dumb Only]** Full hierarchy of the Dumb Scenario. |

---

## 3. Smart Scenario Schema

### 3.1. Scenario Object (`ScenarioEntity`)
Located at `$.scenario.scenario`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | Object | Identifier: `{ "databaseId": Long }`. |
| `name` | String | Scenario display name. |
| `detectionQuality`| Int | (1-100) Speed vs Accuracy tradeoff. |
| `randomize` | Bool | If true, adds random variance to offsets/timers. |
| `keepScreenOn` | Bool | If true, takes a wakelock during execution. |

### 3.2. Event Object (`EventEntity`)
Located at `$.scenario.events[]`. Each event contains a list of conditions and actions.

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | String | Event name. |
| `operator` | Int | 0 (AND) or 1 (OR) for condition logic. |
| `priority` | Int | Execution order in the loop (lower runs first). |
| `enabledOnStart` | Bool | Initial enabled state. |
| `type` | String | `IMAGE_EVENT` or `TRIGGER_EVENT`. |
| `keepDetecting` | Bool | Continue evaluating subsequent events if this one matches. |

### 3.3. Condition Options (`ConditionEntity`)
Located at `$.scenario.events[].conditions[]`. Fields are null if not applicable to the `type`.

#### Common Fields
| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | String | Condition name. |
| `type` | String | `ON_IMAGE_DETECTED`, `ON_BROADCAST_RECEIVED`, `ON_COUNTER_REACHED`, `ON_TIMER_REACHED`. |
| `priority` | Int | Order of check. |

#### Type-Specific Fields
- **ON_IMAGE_DETECTED**
  - `path`: String. Path to the PNG file in the ZIP.
  - `area_left/top/right/bottom`: Int. The expected region of the match.
  - `threshold`: Int (0-100). Minimum similarity for a match.
  - `detectionType`: Int. The detection algorithm (e.g., Template Matching).
  - `shouldBeDetected`: Bool. `true` for presence, `false` for absence.
  - `detection_area_left/top/right/bottom`: Int. The screen region to search.
- **ON_BROADCAST_RECEIVED**
  - `broadcast_action`: String. The Intent action string to listen for.
- **ON_COUNTER_REACHED**
  - `counter_name`: String. The counter key.
  - `counter_comparison_operation`: Enum (`EQUALS`, `LOWER`, `GREATER`, etc.).
  - `counter_operation_value_type`: `NUMBER` or `COUNTER`.
  - `counter_value`: Int. The numerical operand.
  - `counter_value_counter_name`: String. The counter key used as an operand.
- **ON_TIMER_REACHED**
  - `timer_value_ms`: Long. Duration of the countdown.
  - `restart_when_reached`: Bool. Automatically restart the timer.

### 3.4. Action Options (`ActionEntity`)
Located at `$.scenario.events[].actions[]`.

#### Type: CLICK
- `clickPositionType`: `USER_SELECTED` (uses x/y) or `ON_DETECTED_CONDITION`.
- `x`, `y`: Int. Coordinates.
- `clickOnConditionId`: Long. ID of the condition whose detected area should be clicked.
- `pressDuration`: Long. Milliseconds to hold the click.
- `clickOffsetX`, `clickOffsetY`: Int. Variance from the detected position.

#### Type: SWIPE
- `fromX`, `fromY`: Int. Start coordinates.
- `toX`, `toY`: Int. End coordinates.
- `swipeDuration`: Long. Milliseconds for the move.

#### Type: PAUSE
- `pauseDuration`: Long. Milliseconds to wait.

#### Type: INTENT
- `isAdvanced`: Bool. Simple vs Advanced config.
- `isBroadcast`: Bool. `true` for Broadcast, `false` for Start Activity.
- `intent_action`: String.
- `component_name`: String. Specific component to target.
- `flags`: Int. Android Intent flags.
- `intentExtras`: List of `{ type, key, value }`.

#### Type: TOGGLE_EVENT
- `toggleAll`: Bool. Affect all events in scenario.
- `toggleAllType`: `ENABLE`, `DISABLE`, or `TOGGLE`.
- `eventsToggle`: List of individual toggles if `toggleAll` is false:
    - `toggle_type`: `ENABLE`, `DISABLE`, or `TOGGLE`.
    - `toggle_event_id`: Long. ID of the target event.

#### Type: CHANGE_COUNTER
- `counter_name`: String.
- `counter_operation`: `ADD`, `MINUS`, `SET`.
- `counter_operation_value_type`: `NUMBER` or `COUNTER`.
- `counter_operation_value`: Int.
- `counter_operation_counter_name`: String.

#### Type: NOTIFICATION
- `notification_message_type`: `TEXT` or `COUNTER_VALUE`.
- `notification_message_text`: String.
- `notification_message_counter_name`: String.
- `notification_importance`: Int (Android Priority levels).

#### Type: SYSTEM
- `system_action_type`: `BACK`, `HOME`, `RECENT_APPS`.

#### Type: TEXT
- `text_value`: String. The text to input.
- `text_validate_input`: Bool. Simulate "Enter" or "Done" after typing.

#### Type: SCREENSHOT
- `screenshot_path`: String. Optional custom path for saving.

## 4. Dumb Scenario Schema

### 4.1. Dumb Scenario Object (`DumbScenarioEntity`)
Located at `$.dumbScenario.scenario`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | String | Scenario name. |
| `repeat_count` | Int | Number of times to loop the actions. |
| `is_repeat_infinite` | Bool | Ignore count, run until stopped. |
| `max_duration_minutes`| Int | Time limit for execution. |
| `is_duration_infinite`| Bool | Ignore time limit. |
| `randomize` | Bool | Apply random variance to offsets/delays. |

### 4.2. Dumb Action Object (`DumbActionEntity`)
Located at `$.dumbScenario.dumbActions[]`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | String | Action name. |
| `type` | String | `CLICK`, `SWIPE`, `PAUSE`. |
| `priority` | Int | Order of execution. |
| `repeat_count` | Int | Times this specific action repeats. |
| `is_repeat_infinite` | Bool | Repeat action infinitely. |
| `repeat_delay` | Long | Milliseconds between repeats. |
| `x`, `y` | Int | **[CLICK]** Coordinates. |
| `press_duration` | Long | **[CLICK]** Tap duration. |
| `fromX/Y`, `toX/Y` | Int | **[SWIPE]** Path coordinates. |
| `swipe_duration` | Long | **[SWIPE]** Move speed. |
| `pause_duration` | Long | **[PAUSE]** Wait time. |

---

## 5. Statistics and Usage

Both scenario types may include a `stats` object:
- `last_start_timestamp_ms`: Long. When the scenario was last run.
- `start_count`: Long. Total number of execution starts.
